# pkg/nucleus — contract

Lifecycle: `stable`. Split out of `API_CONTRACT_INVENTORY.md` (DX-12):
the machine-auditable contract prose lives here, one file per package, so
the inventory table stays readable for humans.

## Contract scope

`App{}` canonical struct embedding `app.Config` plus Go-only wiring fields (`Modules map[string]ModuleSpec`, `Middleware []Middleware`, `Services []ServiceRegistration`, `Lifecycle LifecycleHooks`, `Options []Option`); `New() *AppBuilder` and `AppBuilder` chain (`FromConfigFile`, `Use`, `Mount`, `WithoutDefaults`, `WithExtensions`, `WithConfigStrict`, `WithUnknownFields`, `Build`, `Start`/`Serve`, `Err`); package-level `Run(App) error` direct-struct surface; generic `Module[C any]` with `Build() ModuleSpec`; **module jobs & webhooks (v1.4.0 — executes the Jobs/Webhooks half of the ADR-013 W3 waiver)** — `JobRegistry` interface (`Register(name string, spec JobSpec) error`) with `JobSpec{Handler func(ctx context.Context) error, Every time.Duration, Cron string, Timeout time.Duration, Singleton bool}` (exactly one schedule required; `Cron` is 5-field or descriptor, validated at registration; executed by the `pkg/tasks` provider selected via `jobs_provider` — `memory` default, `asynq` with `jobs_redis_url`; an invalid registration fails boot), `WebhookRegistry` interface (`Register(path string, spec WebhookSpec) error`) with `WebhookSpec{Handler http.HandlerFunc, Secret string, Methods []string, MaxBytes int64, TimestampTolerance time.Duration}` (route mounts at `<webhooks_prefix>/<module-name><path>`; the registration path must be canonical — a path that `path.Clean` would rewrite (`.`/`..` segments, duplicate or trailing slashes) is a registration error that fails boot, closing the mounted-but-unreachable gap (NU8-2); the path must also have at least one non-empty segment — a bare `/` is a registration error so a webhook cannot mount a catch-all subtree under its module (SEC-4) — and the `<module-name>` segment is itself validated as a single canonical path segment (no slashes, whitespace, or `.`/`..`: a name that would shift the mount off the module's subtree fails boot, SEC-4); when `Secret` is set the HMAC-SHA256 body signature in `WebhookSignatureHeader` (`X-Nucleus-Signature`, format `sha256=<hex>`) is enforced — 401 before the handler; method allow-list defaults to POST-only → 405; body cap defaults to 1 MiB → 413; the webhook prefix is CSRF-exempted automatically when `csrf_enabled` is on; **anti-replay is a declared limit**: the signature authenticates content, not freshness — handlers deduplicate by event ID; `TimestampTolerance > 0` (additive, NU8-3, opt-in because it changes the signed material) switches to the timestamped scheme: the send time travels as decimal Unix seconds in `WebhookTimestampHeader` (`X-Nucleus-Timestamp`), must lie within ±tolerance of the receiver's clock, and the signature covers `<timestamp>.<body>`; zero keeps the body-only scheme; negative or Secret-less tolerance is a registration error), helpers `SignWebhookBody(secret string, body []byte) string` and `SignWebhookBodyWithTimestamp(secret string, ts time.Time, body []byte) (signature, timestamp string)` (returns both header values for the timestamped scheme), and sentinels `ErrInvalidJobSpec` / `ErrInvalidWebhookSpec`; `Router` interface (`Get`, `Post`, `Put`, `Patch`, `Delete`, `Group`, `Resource`, `With`, `Mount(pattern string, h http.Handler)` — attaches a self-contained `http.Handler` subtree under the module prefix using StripPrefix semantics; the per-module counterpart to the framework's internal router mount, used by pluggable modules such as orbit to mount a sub-application); `Methods(...) MethodSet`; REST verb constants (`Index`, `Show`, `Create`, `Update`, `Patch`, `Destroy`) and sub-interfaces (`Indexer`, `Shower`, `Creator`, `Updater`, `Patcher`, `Destroyer`); `Context`/`Handler`/`Middleware`/`Option`/`Extension` types; config-loader surface — `MaxConfigFileBytes`, `UnknownFieldsStrict`/`UnknownFieldsWarn`/`EnvProduction` constants, sentinels `ErrConfigFileTooLarge`, `ErrUnsupportedConfigFormat`, `ErrUnknownConfigKeys`, `ErrSecurityKeyNotNullable`, `ErrMixedConfigFormats`, `ErrInvalidUnknownFieldsMode`, `ErrInvalidConfigValue` (ADR-010 §2 layer-3 field-semantic validation — range/enum/duration), `ErrInvalidConfigReference` (ADR-010 §2 layer-4 referential validation — smtp_host/smtp_port↔mail_driver, samesite↔secure, and module `Requires()`→configured database alias), `ErrInvalidModuleConfig` (ADR-010 §2 layer-5 module-specific config binding/validation — binds `modules.<name>.*` into the typed `Module[C].Config`, applies `default:` tags, enforces `validate:` tags); effective-config inspection (ADR-010 Phase 3a) — `LoadEffective(paths, extraKeys...) (EffectiveConfig, error)` and the `ConfigSource{Kind, Path, Line}` / `EffectiveValue{Key, Value, Source, Redacted}` / `EffectiveConfig{Values}` types (`ConfigSource.Kind` ∈ `default` / `yaml` / `toml` / `json` for file-backed snapshots, `env` for a `NUCLEUS_`-prefixed override (Phase 3.1, `Path` = variable name), and `runtime` for the direct-struct / no-file-builder fallback (Phase 3b); `ConfigSource.Line` is the 1-based source line for YAML files, 0 elsewhere — additive in Phase 3.1); **`Runtime` interface** (ADR-010 Phase 4, Gap 1; extended ADR-019 Slice 1a, Slice 1c) — `DB() *sql.DB`, `DBForRequest(r *http.Request) (*sql.DB, error)`, `AutoMigrate(models ...any) error`, `Logger() *slog.Logger`, `Session() *auth.SessionManager`, `Authorizer() *authz.Enforcer`, `Mailer() mail.Sender`, `Storage() storage.Store`, `JWT() *auth.JWTManager` (nil when no signing material is configured), `Models() *model.Registry` (the application's shared model registry — same instance the framework registers every module's declared models into; read by generic data-browsing modules such as orbit; nil on an unbacked runtime), `Databases() map[string]*sql.DB` (snapshot of all managed database handles keyed by alias; unlike `DB()` this exposes every alias for a module that browses across a multi-database or multi-tenant topology; the returned map is a copy and handles remain framework-owned), `DatabaseHandle() *db.DB` (the engine-aware `*db.DB` wrapper for the default database — exposes `Engine()`/`System()` and the dialect-aware `NewMigrator` that the raw `*sql.DB` from `DB()` cannot provide; returns nil on an unbacked runtime; the handle is framework-owned and must not be closed; most modules should use `DB()` instead), `DatabaseHandles() map[string]*db.DB` (snapshot of every managed `*db.DB` wrapper keyed by alias — the engine-aware counterpart to `Databases()`; intended for a deep module such as orbit that needs per-database dialect detection and migration capability across a multi-database topology; the map is freshly allocated, handles remain framework-owned and must not be closed; nil on an unbacked runtime; most modules should use `Databases()` instead), `Observability() EventBus` (returns the first-party observability bus adapter for this module's live activity feed — ADR-019 Slice 1c, A2 decoupling decision; the adapter is an unexported type that wraps `pkg/observability.Bus` and handles pooled-event `Release` internally, so callers never see `pkg/observability` types); **first-party event surface** — `EventBus` interface (`SubscribeSQL() (<-chan SQLEvent, func())`, `SubscribeHTTP() (<-chan HTTPEvent, func())`, `EmitSQL(ev SQLEvent)`) — a stable, first-party view of in-process bus activity intended for a module's live feed (e.g. orbit's live SQL/HTTP view); the cancel func returned by each Subscribe call MUST be called when the consumer is done — the channel closes automatically after cancel, and slow consumers drop events silently; `EmitSQL` (ADR-020) is the emit counterpart to `SubscribeSQL` — a public SQL ingest that lets an external producer (e.g. an ORM bridge) publish a SQL-statement event onto the same feed without importing `pkg/observability`; the adapter converts the `SQLEvent` value into the bus's pooled event and copies the caller's `Args` (the inverse of the internal `toSQLEvent`); Args are emitted verbatim, so producers carrying sensitive arguments must sanitize before calling; `SQLEvent` (value-copy fields: `Query`, `Args`, `Duration`, `Err`, `Operation`, `ModelName`, `RequestID`, `TraceID`, `UserID`, `NodeID`, `EmittedAt`, and `RowsAffected` — additive v1.1.0, the driver-reported exec row count, 0 = not reported) and `HTTPEvent` (value-copy fields: `Method`, `Path`, `Status`, `Duration`, `RequestID`, `TraceID`, `UserID`, `RemoteIP`, `UserAgent`, `PayloadPreview`, `NodeID`, `EmittedAt`) are detached value copies of the bus's pooled events — no reference back to `pkg/observability` types is exposed on the `pkg/nucleus` stable surface — the stable handle delivered to module lifecycle hooks; bound to the module's `DefaultDB` alias, framework-owned (modules must not close it); **OpenAPI mount** (ADR-010 Phase 4, Slice 2; re-signed to stdlib 2026-07-08, v1 gate A-1a / DEP-2026-008) — `OpenAPISpec{Pattern string, Handler http.Handler}` type, `App.OpenAPI *OpenAPISpec` Go-only wiring field (`yaml:"-"`), and `AppBuilder.WithOpenAPIHandler(pattern string, handler http.Handler) *AppBuilder` — these mount a JSON OpenAPI document endpoint via `app.App.MountOpenAPIHandler`; the handler is typically `openapi.Handler(provider)` but any `http.Handler` serving the document works; a nil handler is a deferred builder error; a second call replaces the previous spec (last-wins). The provider-typed members (`OpenAPISpec.Provider`, `AppBuilder.WithOpenAPI`, `app.App.MountOpenAPI`) were **removed in v0.12.0** (DEP-2026-008; MA-2026-008 is the one-line `openapi.Handler(provider)` wrap) — the stable surface is stdlib-only and `pkg/app` no longer imports `pkg/openapi`.

## Notes

Fluent façade over `pkg/app` (ADR-010). Three coexisting entry surfaces — fluent builder, direct struct, bootstrap pattern — produce equal `App{}` values per `pkg/nucleus/equivalence_test.go`. `FromConfigFile` is the Phase 2 loader (Phase 2a: single-file YAML + size cap + strict schema; Phase 2b: TOML/JSON + multi-file merge with `_append`/`_remove` operators + null-revert-to-default + non-nullable security keys + `WithConfigStrict(true)` mixed-format rejection; Phase 2c: `WithUnknownFields("warn")` opt-out from strict schema validation with `NUCLEUS_ENV=production` operator escape hatch). `Resource` registration is auditable — controllers must explicitly satisfy each requested verb's sub-interface or the framework panics at startup (no reflection-based method discovery). ADR-010 Phase 3b added the auth-gated `GET /_/config` runtime endpoint; it was removed in ADR-019 (2026-06-21) when admin was extracted — the endpoint was admin-session-gated and left with the admin subsystem. The Phase 3a CLI path (`nucleus config print --effective`) is unaffected and remains the canonical way to inspect effective configuration. **Module lifecycle (ADR-010 Phase 4, Gap 1):** `ModuleSpec.OnStart(ctx context.Context, rt Runtime) error` and `ModuleSpec.OnShutdown(ctx context.Context, rt Runtime) error` take `nucleus.Runtime` — not `*app.App` — as their second parameter. `Module[C].OnStart` and `Module[C].OnShutdown` func fields carry the same signature with the typed config appended: `func(ctx context.Context, rt Runtime, cfg C) error`. `nucleus.Run` invokes each module's `OnStart` BEFORE registering that module's `Routes`, so route handlers may safely reference resources acquired during startup. `nucleus.Run` also registers each module's `Models()` with the application model registry (behavioural, no new exported symbol).
